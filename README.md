# urbantransit
GTFS parsing to parquet format and tools to use it

Projet Python gere par Pixi.

## Prerequis

- [Pixi](https://pixi.sh/latest/)

## Installation

```bash
pixi install
```

## Execution

```bash
pixi run run
```

## Structure

- `src/urbantransit/` : package Python
- `pixi.toml` : environnement et taches Pixi
- `pyproject.toml` : metadonnees et build Python
